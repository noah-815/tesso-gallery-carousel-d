# Framework D · visual banner variant2 — 갤러리 캐러셀 (Mobile)

Figma `9907:105366` · 디자인 기준 폭 390

`index.html` 한 파일과 `assets/` 로 구성됩니다. 동작은 Framework E 갤러리 캐러셀(`framework-e-gallery-carousel-mobile`)과 같고, 무드와 인디케이터만 D 시안을 따릅니다.

## E 와 다른 점 (D 시안)

| 항목 | D |
|---|---|
| 섹션 | 패딩 56 / 20, 텍스트 ↔ 이미지 간격 32 |
| 타이포 | 오버라인·본문 Pretendard 15 / 제목 Albert Sans Bold 32 · 행간 1.25 |
| 이미지 | 350 × 262.5 (4:3), 모서리 16 |
| 인디케이터 위치 | 이미지 **아래**, 위아래 여백 32 |
| 인디케이터 모양 | 활성 = **바 24×8**, 나머지 dot 8, 간격 8, 색 #111 (비활성 30%) · 전체 71×8 |
| "더 있음" dot | 7px (시안 4번째 dot) |

인디케이터는 시안의 `galleryIndicator` SVG(`assets/gallery-indicator.svg`, 참고용으로 보관)의 좌표·크기·색을 그대로 CSS 로 옮겼습니다. 상태에 따라 바가 움직여야 해서 한 장짜리 SVG 를 그대로 쓰지 않았습니다.

## 동작

| 항목 | 내용 |
|---|---|
| 전환 | 가로 슬라이드(translateX) 500ms. 다음: 현재 이미지가 왼쪽으로 나가고 다음 이미지가 오른쪽에서 들어옴 |
| 전환 옵션 | **박스 안**: 이미지 박스 가장자리에서 잘린 채 두 장이 함께 밀림 · **화면 밖에서**(기본): 박스에서 자르지 않고 화면(390 프레임) 가장자리에서 자름. 이미지 사이 간격 20(섹션 좌우 여백) → 다음 이미지가 화면 오른쪽 끝 바로 밖에서 밀려들어오고, 나가는 이미지는 화면 왼쪽 밖으로 나감 |
| 루프 | 마지막 ↔ 처음도 같은 방향으로 이어서 슬라이드 |
| 자동 넘기기 | 데모 패널에서 on / off, 간격 2–5초 (기본 on · 3초) |
| 조작 | 스와이프/드래그, 인디케이터 클릭, 키보드 ← → |
| 인디케이터 | 최대 4개. 진행 방향에 이미지가 더 남아 있으면 활성 바가 끝이 아니라 끝에서 두 번째 칸에 머물고 줄이 한 칸씩 밀림. 끝에 도달하면 마지막 칸으로 |
